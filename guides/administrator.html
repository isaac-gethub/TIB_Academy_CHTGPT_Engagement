Administrator User Guide — v5.0

Production application: Return to Academy. This online guide accompanies the Word v5.0 user guides. The Academy does not connect directly to SAP. Use only authorised SAP access and approved evidence.

Course structure

Thornfield Level 1: TF-01–TF-24 (24 modules). Corvane Level 2: CV-01–CV-26 (26 modules). The final four modules in each project extend the original tutorial scope following job-role gap analysis.

Unified six-stage workflow

  1. Understand the assignment: Read the control objective, risk, scope and expected evidence.
  2. Execute SAP activities: Use the activity selector and Previous/Next activity buttons. Follow A1–A6 navigation, selections, output and evidence guidance. Activity Next stops at the final execution activity.
  3. Capture evidence: Complete the evidence fields, record source system/client, selections, actual count, date, screenshots and evidence IDs.
  4. Analyse results: Distinguish facts from assumptions and identify exceptions.
  5. Conclude and validate: Follow B1–B3 guidance, document supported conclusions and open items.
  6. Save and submit: Review the workpaper, save to cloud where available and submit for Controls Lead review.

Navigation distinction: Previous/Next activity moves within a guide; Previous/Next stage moves between the six overall learning stages. Completing B3 does not prevent proceeding to Stage 6.

Administrator operations

  1. Maintain authorised Academy users and role assignments. Do not share account credentials.
  2. Assign SAP Hands-On or SAP Simulation mode using existing administrative controls. Trainees should not bypass their assigned training environment.
  3. Ensure both project selectors expose TF-01–TF-24 and CV-01–CV-26 and that each module has its own workpaper ID.
  4. Verify Stage 2 displays activity-specific navigation, SAP transaction guidance, selection fields, output interpretation and evidence steps; verify Stage 5 includes B1–B3 conclusion guidance.
  5. Confirm the last activity disables its Next activity button but that the overall wizard can still advance to Stage 6.
  6. Check evidence submission, cloud save, trainee-to-Lead assignment and review access. Maintain role separation.
  7. Preserve all existing modules and project data during content updates; do not modify unrelated Academy applications.

Release governance

Deployment READY is not the same as formal QA acceptance. Test sign-in, role permissions, mode assignments, all 50 modules, workpaper cloud persistence, evidence handling, submission, Lead approval and recovery before certifying production operation.

Security and integrity

The Academy does not perform live SAP transactions. Hands-On trainees access SAP separately with approved credentials. Simulated evidence must be marked SIMULATED; confidential client production data must not be uploaded without approval.
